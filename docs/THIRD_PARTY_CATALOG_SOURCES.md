# Supplemental catalog sources

Japanese, Korean and Traditional Chinese data: https://github.com/type-null/PTCG-database.
The original official source page, official image address and Git revision are
retained per imported record. Pokémon card artwork and trademarks remain with
their respective owners; the software license below is not an artwork license.

Thai and Indonesian data: official https://asia.pokemon-card.com/ card lists.
The Cardyssey parser is independent and preserves language, explicit product
code and printed number. No cross-language image substitutions are made.
